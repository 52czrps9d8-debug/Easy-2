# Работа с роликами (OpenMontage)

Отвечай пользователю по-русски.

OpenMontage стоит в `../OpenMontage` (ставит `./install.sh`, в облаке — скрипт
подготовки окружения). Перед работой над роликом прочитай
`../OpenMontage/AGENT_GUIDE.md` и следуй ему: этапы пайплайна, навыки из
`../OpenMontage/skills/` и `../OpenMontage/.agents/skills/`, контрольные точки.
Команды Python запускай из `../OpenMontage` через `.venv/bin/python`.

## Деньги

- Перед каждой платной генерацией назови инструмент, модель, причину выбора и
  жди согласия. Не меняй модель или сервис без согласия.
- chad (`chadgpt_image`) платит рублями/искрами с баланса пользователя;
  `chadgpt_video` экспериментальный и выключен.

## Приоритет источников: сначала Pixabay

Ключ: переменная окружения `PIXABAY_API_KEY` (бесплатный). Pexels недоступен —
Pexels не выдаёт новые ключи.

1. **Стоковые видео** — сначала Pixabay:
   - `video_selector`: `preferred_provider: "pixabay"`;
   - `corpus_builder` / `direct_clip_search`: `sources: ["pixabay_video"]`,
     и только если там мало подходящего — добавь бесплатные источники без
     ключей: `"mixkit", "dareful", "wikimedia", "archive_org", "nasa", "esa",
     "noaa"` (их хосты может понадобиться открыть в окружении).
2. **Фото и картинки** — сначала `pixabay_image`
   (`image_selector`: `preferred_provider: "pixabay"`), затем бесплатные
   источники; генерация (`chadgpt_image` и др.) — только если стока не хватает
   и пользователь согласен платить.
3. **Музыка** — сначала `pixabay_music`, затем `music_library/`, затем остальное.
4. Если Pixabay не нашёл подходящего — скажи об этом и предложи следующий
   источник, а не переключайся молча.

## Файлы

- Контейнер временный: готовые ролики и картинки сразу отправляй пользователю
  (SendUserFile). Больше ~30 МБ — предложи передать иначе.
- Большие файлы пользователь присылает публичной ссылкой на Яндекс Диск или
  Google Диск; для скачивания может понадобиться открыть хосты диска в окружении.
- Ключи и пароли никогда не печатай и не коммить. Репозиторий публичный.
